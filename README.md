Enhance your AutomatePro experience with custom extensions and layouts for Foxglove Studio.

## Installation
Before proceeding, ensure that Foxglove Studio is installed on your device. Follow these steps to download and install the extensions and layouts from this repository.

### Getting Started
Clone this repository or download the files directly to your local machine.

### Extensions
To install an extension:

1. Open Foxglove Studio.
2. Navigate to Settings.
3. Select Extensions > Install Local Extension.
4. Locate and select the downloaded file with the .foxe extension.

### Layouts
To import a layout:

1. Open Foxglove Studio.
2. Go to the Dashboard.
3. Click on Layouts > Import from File.
4. Choose the downloaded .json file.

For any issues during installation or usage, please refer to our [support page](https://docs.lemvos.com) or open an issue in this repository.
